# Forest bot

## Preparation
1. Download forest archive from 
[here](https://drive.google.com/drive/folders/1b_hEjnkQfP8ZVP-OEbnYWqoGSFwXMAP3?usp=sharing)
to `data/forest_archive` folder.
2. copy `.env.example` to `.env` and fill in the required values.
```bash
cp .env.example .env
```
## Running
Run docker compose to start the service.
```bash
docker compose up
```
